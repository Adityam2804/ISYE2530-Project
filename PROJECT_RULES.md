# Project Rules

## 1. Dataset choice

Each team chooses a public dataset within one of the approved project tracks:

- Healthcare
- Supply Chain and Logistics
- Humanitarian Operations

The dataset must be approved in Milestone 1 before the team proceeds to Milestone 2.

## 2. Student responsibility

Students are responsible for:

- understanding the dataset
- defining an intended user and recurring decision
- identifying relevant entities and relationships
- making and explaining cleaning decisions
- implementing required TODO functions
- designing a reasonable relational schema
- writing required SQL
- validating outputs
- documenting assumptions and limitations

## 3. Instructor-provided structure

The course provides:

- repository/folder structure
- required deliverables
- Python function signatures
- expected return types
- SQL file locations
- public tests
- database helpers where appropriate
- later application scaffolding

## 4. Code modification policy

You may add helper functions when useful.

You should not:

- rename required functions
- remove required parameters
- change required return types
- bypass TODO functions by hard-coding final outputs
- submit a pre-built external application instead of completing the provided scaffold

## 5. Reproducibility

Another person should be able to place the approved raw dataset in `data/raw/`, run the required code, and recreate the cleaned data and database.
